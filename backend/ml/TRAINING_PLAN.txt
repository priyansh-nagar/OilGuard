1. MODEL ARCHITECTURE
================================================================================

DESIGN: Lightweight CNN with Global Average Pooling

INPUT:  (batch, 1, 400, 400) - Single-channel grayscale SAR patches
OUTPUT: (batch, 1) - Binary logit (oil probability after sigmoid)

ARCHITECTURE:
-------------

Conv Block 1:
  - Conv2d(1 → 32, kernel=3×3, padding=1)
  - BatchNorm2d(32)
  - ReLU
  - MaxPool2d(2×2)
  - Output: 200×200×32

Conv Block 2:
  - Conv2d(32 → 64, kernel=3×3, padding=1)
  - BatchNorm2d(64)
  - ReLU
  - MaxPool2d(2×2)
  - Output: 100×100×64

Conv Block 3:
  - Conv2d(64 → 128, kernel=3×3, padding=1)
  - BatchNorm2d(128)
  - ReLU
  - MaxPool2d(2×2)
  - Output: 50×50×128

Global Pooling:
  - AdaptiveAvgPool2d(1×1)
  - Output: 1×1×128
  - Flattened: 128 features

Classifier:
  - Linear(128 → 64)
  - ReLU
  - Dropout(0.5)
  - Linear(64 → 1)
  - Output: Binary logit

  4. Rain cells (smooth surface)

PRECISION vs RECALL TRADEOFF:
  - High Precision: Fewer false alarms, may miss some oil
  - High Recall: Catch more oil, more false alarms
  - For oil spill detection: Recall may be more important
    (better to investigate false alarm than miss a real spill)
